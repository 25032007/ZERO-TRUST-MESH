Behavioral anomaly detection

Per-pair EWMA baselines detect anomalous request volume, payload size, and call-depth deviations. The backend risk engine calculates and records these as named factors on each decision event. Anomaly factor codes (e.g., BASELINE_SPIKE, PAYLOAD_ANOMALY) are visible in the Live Operations investigation panel when present.

Authoritative source: Anomaly factors are recorded by the backend risk engine. This view does not compute anomalies independently.

Checking…

The audit log is hash-chained: each entry's hash includes the previous entry's hash, creating a tamper-evident chain. Verification confirms that no record has been altered or deleted since logging. A broken chain indicates tampering and constitutes a security event.
